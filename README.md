# Sobre o Projeto

O projeto consiste na criação de uma **calculadora com diversas funções**, utilizando operadores aritméticos e funções nativas da linguagem Python.

A implementação permite realizar cálculos variados de forma simples, servindo como ferramenta prática para reforçar conceitos fundamentais de programação.

---

# Objetivo

- Praticar operadores aritméticos em Python  
- Utilizar funções embutidas da linguagem  
- Desenvolver uma ferramenta funcional de cálculo  
- Aplicar conceitos básicos de programação em um projeto prático  

---

# Conteúdo do Repositório

Este repositório contém:

- **Projeto_final.ipynb**: notebook principal com a implementação da calculadora  

---

# Como utilizar

Para começar:

1. Abra o arquivo `Projeto_final.ipynb`
2. Execute as células passo a passo
3. Utilize a calculadora conforme os exemplos apresentados
